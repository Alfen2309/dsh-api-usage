v0.4.0 为 DeepSeek 数据源补全 token 维度：管理页卡片、7 天柱状图与 90 天热力图都能看到 token 消耗。

## 变更

- **卡片 token 展示**：管理页每张 DeepSeek 卡（登录账号 / API key）的消耗行新增今日 token——`输入 X · 输出 Y · 缓存命中 Z`，拆分口径与计价一致（输入 = 缓存未命中 + 缓存写入，即按输入价计费的部分；缓存命中单独列示）。零用量时字段也完整显示为 0，不再留空。宿主 `/api-usage/summary` 中每个来源的 `spend` 相应新增 `tokens: { input, cacheHit, output }` 字段。
- **双轴柱状图**：近 7 天柱状图从单一金额升级为「金额（蓝，tooltip 固定 `¥` + 两位小数）+ Token（绿）」双 y 轴并排柱——两个量纲差数个数量级，各自独立量程后走势都清晰。图例以 HTML 色点置于图表上方头部行。
- **热力图指标切换**：近 90 天日历热力图新增「金额 | Token」着色切换，Token 用绿色渐变与柱状图同色语言，visualMap 量程随指标重算；tooltip 无论当前着色维度，都完整显示当日金额、token 总量、token 三项明细与调用次数（含搜索次数）。
- **图表布局对齐**：柱状图与热力图统一为「18px 头部行 + 100px 画布」结构，两图顶边对齐、高度一致；echarts 画布内图例移除（`LegendComponent` 不再打包，bundle 减小约 17 KiB），柱状图绘图区更高。
- **tooltip 精修**：结构化多行——加粗日期标题、色点指标行（数值加粗、表格数字）、9px 灰色次要行（token 明细 / 调用次数）；整体字号 10px，内边距收紧，并加 `confine` 防止在卡片边缘被裁剪。柱状图与热力图 tooltip 格式统一。

## 说明

- 数据来源不变：仍是本地账本（仅 DSH 自身调用），本次无任何新增网络请求；`spend.tokens` 为增量字段，旧前端可忽略，无破坏性接口变更。
- token 明细口径：图表中 token = 缓存命中 + 未命中 + 缓存写入 + 输出之和；卡片「输入」= 未命中 + 缓存写入。
- GLM 卡片本次未加图表（GLM 用量历史无官方 API，方案评估后暂缓）。
- 升级后建议刷新页面；宿主侧改动在 DSH HMR 下自动重载，未生效时重启 DSH。
